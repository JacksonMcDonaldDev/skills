# Personal

Skills tied to my own setup, not promoted in the plugin.

- **[capture-source](./capture-source/SKILL.md)** — Capture a source (YouTube video, article, file) into the learning KB: file raw, distill a source note, link it into the knowledge web.
- **[copy-commands](./copy-commands/SKILL.md)** — Copy the shell commands Claude just suggested into the Wayland clipboard, without hard-wrap line-break artifacts: as one block, or one at a time via cliphist.
- **[fleet](./fleet/SKILL.md)** — Operate the machine fleet, host-aware (Mac controller or bigbox itself): reachability/tunnel preflight, wake bigbox via helios WoL API, remote-mode toggle, agent dispatch over SSH/tmux.
- **[handoff-with-agent](./handoff-with-agent/SKILL.md)** — Write a handoff file via `handoff`'s rules, then open a new cmux tab (or terminal window) with a fresh agent already cold-starting on it; degrades to handing you the command.
- **[learn](./learn/SKILL.md)** — Capture an unfamiliar concept as a thread in the learning queue (`~/kb/learning/threads/`) for later study.
- **[obsidian-vault](./obsidian-vault/SKILL.md)** — Search, create, and manage notes in an Obsidian vault with wikilinks and index notes. Inherited from upstream and **not yet repointed** — its vault path is still Matt's WSL `/mnt/d/Obsidian Vault/AI Research/`, which exists on neither machine.
- **[ship](./ship/SKILL.md)** — Implement work from a spec or tickets, test-first, then review: a hardened `/implement` that actually invokes `tdd` and `code-review` rather than mentioning them.
- **[study](./study/SKILL.md)** — Socratic study session over the learning queue in `~/kb/learning`: quiz first, then correct, then reschedule.
- **[tailor-resume](./tailor-resume/SKILL.md)** — Tailor a Reactive Resume JSON export to a specific job posting (strictly truthful), emitting a re-importable JSON plus an interview-prep gap report.
